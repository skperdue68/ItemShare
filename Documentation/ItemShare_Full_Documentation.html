ItemShare for Elder Scrolls Online

ItemShare is an ESO addon that lets players mark tradeable items as shareable in-game, save that data to saved variables, and then import it to the ItemShare site for guild-wide or group-wide request tracking.

What the Addon Does

ItemShare adds right-click menu options to supported inventory entries so you can quickly add or remove items from your shared list. The addon tracks those items and saves the data so it can be uploaded to the ItemShare site.

  • Adds right-click options to inventory items allowing you to add or remove them from the shared list
  • Prevents adding items that are bound or temporarily tradeable
  • Displays a badge on items marked as shared, on standing offers, and on items that keep a reserve
  • Keeps a standing offer with Always Share This Item, even when you hold none of that item
  • Offers only what you hold above a number, with a share reserve
  • Keeps track of item counts and where items are stored
  • Provides a dedicated window (/itemshare list) showing your shared items
  • Saves all shared data so it can be uploaded to the site
Only items that are actually eligible to be shared can be added. If an item is bound to you, or restricted to temporary group trading, the addon will not present the share option.

Requirements

  • LibCustomMenu is required for the right-click context menu integration.
  • The addon uses the saved variable file ItemShareSavedVars.

Supported Locations

ItemShare can track shared items from multiple storage locations. The location is preserved and exported with the item.

  • Inventory
  • Bank
  • Craft Bag
  • House Storage / Furnishing Vault (including placed furniture)
  • Guild Bank (off by default; /ishare guildbank toggles it)

Commands

/itemshareShows the command list.
/itemshare listOpens or closes the Shared Items window.
/itemshare resetClears every share and every standing offer. clear is an alias.
/itemshare syncRecounts shares against the bags that are readable now and drops the ones you no longer have. Standing offers are left alone. cleanup and reconcile are aliases.
/itemshare rebuildRewrites every share from your current bags. It also runs on login and when a bank opens or closes.

/itemshare guildsLists the guilds captured for the current character.
/itemshare alwaysLists the items you always offer, whether or not a copy is in your bags.
/itemshare noalways <part of the name>Stops always sharing one item.
/itemshare reserve <amount> <part of the name>Keeps that many back and offers the rest.
/itemshare noreserve <part of the name>Shares the whole stack again.

/itemshare guildbankToggles sharing from the guild bank, which is off by default.

Guild names and IDs are stored once, by guild ID, and every share is matched to them; the addon no longer copies the list onto each item. Because the website reads the older layout, /itemshare export writes a complete compatibility copy to a second saved-variables file, ItemShareExport.lua. Upload that file until the site reads the guild table directly.

Alias: /ishare

List Window

The Shared Items window (/itemshare list) shows all items that are currently marked for sharing.

  • Right-click a row to turn sharing off
  • Right-click again to turn sharing back on
  • Left-click the item name to view detailed item information

Only rows that offer something are listed: every share with something above its reserve, plus any standing offer that has a copy in your bags even if that copy was never marked by hand. A row with a reserve says keep N beside its location.

Always Sharing an Item

Right-click an item and choose Always Share This Item to make it a standing offer. It stays offered even when you no longer hold a copy, and /ishare sync never removes it. A normally shared item is different: it is only offered while it is in a bag the addon can read, and it disappears from the list once it is gone.

Use /ishare always to list your standing offers, and /ishare noalways <part of the name> or Stop Always Sharing on the item's menu to end one.

Share Reserve: Offer Only What You Hold Above a Number

Give an item a share reserve and the addon offers only the quantity above that number. The list recalculates whenever your inventory changes, so a share that is entirely inside its reserve stays marked at zero and comes back on its own once you acquire more.

CommandEffect
/ishare reserve 12 soul gemKeep 12; holding 20 shares 8
/ishare reserve 12 soul gemUse 15 later, so 3 are shared
/ishare reservesList everything that has a reserve
/ishare noreserve soul gemShare the whole stack again

Setting a reserve from the item's right-click menu

You never have to type the command. Right-click the item and choose Share Reserve:

  1. The Share Reserve window opens with the item already named, above the prompt "Keep how many back? They are not offered while you hold this many or fewer."
  2. Type the number in the box, then click Keep This Many. The addon reports what is now shared, for example keeping 12 back, so 8 of 20 held are shared.
  3. Anything that is not a whole number of at least 1 is refused in red with "Enter a whole number of 1 or more." and the box keeps focus, so the reserve is never saved as something invalid.

The window also carries a Clear Reserve button, which drops the reserve and shares everything held; Escape or the close button leaves the item as it was. Once a number is set, the item's menu changes to Share Reserve: Keep N Back... to change it and Clear Share Reserve to remove it without opening the window at all.

The menu entry shows up wherever the item's right-click menu does - your inventory, the bank, house storage and the furnishing vault - and the reserve belongs to the item rather than to one copy, so it stays with the item when that copy leaves your bags. The slash command is simply another way in: the name only has to be part of the item name, and it is refused if it matches more than one shared item. A reserve covers standing offers too: the offer only shows while you hold more than the reserve.

Badges on the Item Icon

The badge on an item icon shows which kind of share it is. Hovering it says which state it is in and, when there is a reserve, how much is being kept back.

  • Green gift - shared right now.
  • Gold gift with a closed ring - always shared; the badge stays on the item even when you hold none of it.
  • Amber padlock tag - added to either badge when the item keeps a share reserve.
  • Padlock on its own - a reserve left on an item that is not shared at all, so it stays visible and can be cleared.

How Saving Works

ESO only writes saved variables at the appropriate time, so after marking items you should run /ishare save or reload the UI. The addon stores the data in your saved variables file, which can then be uploaded to the site.

  1. Mark items in-game using Add to Share.
  2. Run /ishare save or reload the UI.
  3. Locate your saved variables file.
  4. Upload that file through the ItemShare site.
The saved variables file is typically located in the ESO SavedVariables folder and is named ItemShareSavedVars.lua and holds the saved variable data for ItemShare. The site reads that file when it is uploaded.

Typical Workflow

  1. Install the addon and LibCustomMenu.
  2. Mark eligible items in-game as shareable.
  3. Use /ishare save to write the latest data.
  4. Open the ItemShare site.
  5. Upload the saved variables file there.
  6. Use the site's item list to request items.
  7. Fulfill requests and remove completed items from the list as needed.

Notes and Limitations

  • Bound items cannot be shared.
  • BoP group-trade items are intentionally blocked.
  • The site is a separate step: the addon only writes the saved variables file.

Known Issues

  • Guild bank sharing is off by default while it is being tested; /ishare guildbank toggles it
  • If an item is marked as shared while in the Furnishing Vault and is later placed in a house, it will continue to show as shared. This behavior may change in a future update
